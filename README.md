# Diagnóstico de equipo IENN

Encuesta de diagnóstico de equipo (Inteligencia Colaborativa) con un panel privado de resultados en vivo: promedio por dimensión, dispersión, NPS, áreas de oportunidad y comparación por antigüedad.

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).

## Importante

La página guarda y lee las respuestas con el almacenamiento y la identificación de usuarios de los artefactos de Claude (`window.claude`). Por eso solo funciona publicada como artefacto en claude.ai. Si se abre desde GitHub Pages o desde un archivo local, se ve la encuesta pero no puede guardar respuestas ni mostrar el panel.

Este repositorio es el respaldo del código. No contiene respuestas ni datos del equipo.
